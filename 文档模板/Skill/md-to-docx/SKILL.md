# MD to DOCX 转换工具

## 概述

将 Markdown 文档转换为 Word 格式文档，**转换后无需任何手动调整，可直接交付**。

## 核心目标

| 目标 | 说明 |
|------|------|
| **开箱即用** | 转换后的 Word 文档可直接交付，无需手动调整 |
| **格式保真** | MD 中的格式、样式完整保留到 Word |
| **100% 合规** | 必须通过 format-validator 检查 |

## 能力

- **格式转换**：MD → DOCX，使用 Word 模板保持格式一致
- **模板化转换**：所有格式在模板中预定义，转换时自动应用
- **图片处理**：自动处理文档中的图片引用并嵌入
- **目录自动生成**：使用 --toc 参数自动生成目录
- **格式校验**：转换后自动调用 format-validator，确保 100% 合规

## Word 模板规范

**模板必须符合 Word文档格式规范标准V1.0.md 的所有要求**

### 模板制作要点

| 规范项 | 要求 | 依据章节 |
|--------|------|---------|
| **字体** | 宋体（正文）、加粗（标题） | 一、字体与字号规范 |
| **字号** | 标题：三号/四号/小四，正文：小四，表格：小四 | 一、字体与字号规范 |
| **首行缩进** | 正文段落首行缩进2字符 | 二、首行缩进规范 |
| **行距** | 正文1.5倍行距，标题按层级设置 | 三、间距规范 |
| **对齐** | 标题左对齐，总标题居中，正文左对齐 | 四、对齐方式规范 |
| **列表** | 有序列表 1.、2.，无序列表 ● | 五、列表规范 |
| **表格** | 统一添加标准边框，单元格上下边距0.3cm | 六、表格规范 |
| **页面** | A4，纵向，上2.5cm/下2.5cm/左2cm/右2cm | 八、页面设置规范 |

### 表格样式要求（关键）

- 表格外边框：1.5pt 黑色实线
- 表格内边框：0.75pt 黑色实线
- 表头背景色：可选择浅灰色填充
- 表头字体：宋体、小四、加粗、居中

### 页眉页脚设置

| 位置 | 内容 | 格式 |
|------|------|------|
| 页眉 | 文档总标题 | 宋体、小四、居中 |
| 页脚 | 页码（底部居中） | 宋体、小四 |
| 页眉距边界 | 1.5cm | - |

### 禁止在模板中出现的内容

| 禁止项 | 说明 |
|--------|------|
| 手动换行符 | 所有换行通过段落设置实现 |
| 格式多样 | 同一类内容只能有一种格式 |
| 艺术字体 | 禁止使用艺术字体、异体字 |
| 随意边框 | 禁止随意修改表格边框、列宽 |

## 核心流程

```
Step 1: 模板验证
  - 确认 Word 模板符合 Word文档格式规范标准V1.0.md
  - 确认表格样式带边框
  - 确认页面设置正确

Step 2: MD 文档检查
  - 验证 MD 语法正确性
  - 检查图片路径有效性（使用相对路径）
  - 确保文档结构完整（标题层级清晰）
  - 确保使用的符号符合规范

Step 3: 执行转换（使用模板）
  - pandoc --reference-doc=模板.docx
  - 添加 --toc 参数自动生成目录
  - 指定 --resource-path 确保图片正确嵌入

Step 4: 格式校验（调用 format-validator）
  - 必须 100% 通过格式检查
  - 依据：Word文档格式规范标准V1.0.md
  - 如有不合格项 -> 返回 Step 1 修复模板或 MD

Step 5: 最终交付
  - 格式 100% 合格 -> 直接交付
  - 不合格 -> 修复问题后重新转换
```

## Pandoc 转换命令

### 推荐命令

```bash
pandoc input.md -o output.docx --reference-doc=template.docx --toc --toc-depth=3 --resource-path=./images
```

### 参数说明

| 参数 | 说明 |
|------|------|
| --reference-doc=template.docx | 使用模板文件 |
| --toc | 自动生成目录 |
| --toc-depth=3 | 目录包含到三级标题 |
| --resource-path=./images | 图片资源路径 |

## MD 写作规范

为确保转换质量，MD 写作时需遵守：

| 规范 | 说明 | 错误示例 | 正确示例 |
|------|------|---------|---------|
| 图片路径 | 使用相对路径 | C:\\img\\a.png | ./images/a.png |
| 标题层级 | 连续不跳跃 | # 一级 ### 三级 | # 一级 ## 二级 ### 三级 |
| 列表符号 | 有序用 1.、2.，无序用 ● | - 列表 | 1. 列表 或 ● 列表 |
| 表格格式 | 使用标准 MD 表格 | 合并单元格 | 标准 Markdown 表格 |

## 质量门禁

```
格式检查（调用 format-validator）
  - 依据：Word文档格式规范标准V1.0.md
  - 关键项合格率 < 100% -> 拒绝交付
  - 表格无边框 -> 拒绝交付
  - 页眉页脚缺失 -> 拒绝交付
  - 目录未生成 -> 拒绝交付

图片检查
  - 图片无法加载 -> 拒绝交付
  - 图片位置异常 -> 拒绝交付
```

重要：转换后的 Word 文档必须无需任何手动调整即可交付。

## 产出内容

- 转换后的 Word 文档（可直接交付）
- 转换日志
- 格式验证报告（100% 合格）

## 禁止行为清单

1. 禁止不使用模板 - 必须使用符合格式规范的 Word 模板
2. 禁止转换后手动调整格式 - 如果需要调整，说明模板或 MD 有问题，应修复源头
3. 禁止表格不带边框 - 表格边框必须在模板中定义
4. 禁止跳过格式校验 - format-validator 100% 合格是交付前提
5. 禁止使用绝对路径图片 - 图片必须使用相对路径
6. 禁止使用不规范符号 - 必须使用 1.、2. 和 ●

## 关联 Skill

- **format-validator**：转换后自动调用校验格式，依据 Word文档格式规范标准V1.0.md
