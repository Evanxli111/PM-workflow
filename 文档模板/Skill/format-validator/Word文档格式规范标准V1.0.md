# 文档格式规范标准（Word生成标准）

**版本：V1.0**

**创建日期：2026/04/09**

**适用范围：PRD文档、系统操作手册等交付文档的Word格式生成**

---

## 一、字体与字号规范

### 1.1 全文字体

| 内容类型 | 字体 | 说明 |
|----------|------|------|
| Windows系统 | 宋体 | 默认字体 |
| Mac系统 | 思源宋体 | 替换宋体 |
| 全文字体要求 | 禁止使用艺术字体、异体字 | 保持专业统一 |

### 1.2 字号规范

| 内容类型 | 字体 | 字号 | 说明 |
|----------|------|------|------|
| 文档总标题 | 宋体 | 加粗、小二号（22pt） | 全局唯一 |
| 一级标题（如"一、文档前言"） | 宋体 | 加粗、三号（16pt） | 左对齐 |
| 二级标题（如"1.1 文档目的"） | 宋体 | 加粗、四号（14pt） | 左对齐 |
| 三级标题（如"4.1.1 操作前提"） | 宋体 | 加粗、小四（12pt） | 左对齐 |
| 正文内容 | 宋体 | 常规、小四（12pt） | 首行缩进2字符 |
| 表格表头 | 宋体 | 加粗、小四（12pt） | 居中 |
| 表格内容 | 宋体 | 常规、小四（12pt） | 无首行缩进 |
| 强调内容 | 宋体 | 加粗、小四（12pt） | 表示重要 |
| 警示内容 | 宋体 | 加粗、小四（12pt）、红色 | 仅限风险提示 |
| 页码/页眉 | 宋体 | 常规、小四（12pt） | 无加粗 |

---

## 二、首行缩进规范

| 内容类型 | 首行缩进 | 说明 |
|----------|----------|------|
| 完整正文段落 | 缩进2字符 | 标准段落 |
| 列表项 | 缩进2字符 | 与正文一致 |
| 备注/补充说明 | 无需缩进 | 不足一行的短注释 |

---

## 三、间距规范

### 3.1 行距

| 内容类型 | 行距 | 说明 |
|----------|------|------|
| 文档总标题与下方内容 | 2倍行距 | 标题与内容区分隔 |
| 一级标题与章节结尾 | 1.5倍行距 | 上一级标题到一级标题 |
| 一级标题与二级标题 | 1倍行距 | 标题层级区分 |
| 二级及以下标题与上一级 | 0.5倍行距 | 紧凑排版 |
| 最细级标题与正文 | 0.5倍行距 | 标题与内容衔接 |
| 正文段落 | 1.5倍行距 | 正文阅读舒适 |
| 列表项 | 1.5倍行距 | 与正文统一 |
| 表格内文本 | 单倍行距 | 紧凑表格 |
| 章节之间（不同一级章节） | 2倍行距 | 章节分隔 |
| 同一一级章节下不同模块 | 1倍行距 | 模块分隔 |
| 截图与上下内容 | 0.5倍行距 | 图片与文字衔接 |
| 截图说明与截图 | 0.3倍行距 | 说明紧跟图片 |

### 3.2 段落/元素间距

| 元素关系 | 间距 | 说明 |
|----------|------|------|
| 同一章节内不同正文段落 | 0.5倍行距 | 段落分隔 |
| 列表项之间 | 单倍行距 | 紧凑列表 |
| 列表与上一段落/标题 | 0.5倍行距 | 列表前间距 |
| 表格与上下文内容 | 上下各1倍行距 | 表格与文字分隔 |
| 版本说明表与一级标题 | 2倍行距 | 特殊分隔要求 |
| 截图与上下文内容 | 上下各1倍行距 | 图片与文字分隔 |

### 3.3 单元格边距

| 内容 | 边距设置 | 说明 |
|------|----------|------|
| 表格单元格上下边距 | 0.3厘米 | 标准单元格内边距 |
| 表格单元格左右边距 | 默认 | 根据内容自适应 |

## 四、对齐方式规范

| 内容类型 | 对齐方式 | 禁止 |
|----------|----------|------|
| 文档总标题 | 居中对齐 | - |
| 各级标题（一级至三级） | 左对齐 | 居中、右对齐 |
| 正文段落 | 左对齐 | 两端对齐 |
| 表格整体 | 居中对齐 | - |
| 表格表头/表体 | 居中对齐 | 数值、日期类 |
| 表格内容（文本类） | 左对齐 | - |
| 截图 | 居中对齐 | - |
| 截图相关文本 | 左对齐 | - |
| 页码 | 页面底部居中 | - |
| 页眉 | 居中对齐 | - |
| 警示/强调内容 | 左对齐 | 可缩进2字符 |

## 五、列表规范

### 5.1 有序列表

| 规范项 | 要求 |
|--------|------|
| 序号格式 | "1.、2.、3." |
| 序号后 | 加顿号 |
| 对齐方式 | 左对齐 |
| 首行缩进 | 无 |
| 序号连续 | 无跳号 |

### 5.2 无序列表

| 规范项 | 要求 |
|--------|------|
| 符号 | "●"（实心圆点） |
| 对齐方式 | 左对齐 |
| 首行缩进 | 无 |

### 5.3 嵌套列表

| 级别 | 符号 | 缩进 | 行距 |
|------|------|------|------|
| 一级 | "1.、2.、3."或"●" | 无 | 1.5倍 |
| 二级 | "①、②、③"或"■" | 2字符 | 1.5倍 |

## 六、表格规范

### 6.1 表格样式

| 规范项 | 要求 |
|--------|------|
| 边框 | 统一添加标准边框 |
| 列宽 | 适配内容，无溢出 |
| 内容 | 无多余留白 |
| 文本 | 无首行缩进 |
| 行高 | 适配文本高度 |

### 6.2 表格排版要求

- 全文档所有表格均按统一规范排版
- 无特殊例外
- 禁止随意修改表格边框、列宽

## 七、截图相关规范

### 7.1 截图标注

| 内容 | 格式 | 示例 |
|------|------|------|
| 截图说明 | "图X-X XX页面" | "图4-1 系统登录页面" |
| 位置 | 左对齐 | - |
| 与截图间距 | 0.3倍行距 | 说明紧跟图片上方 |

### 7.2 截图要求

| 要求项 | 说明 |
|--------|------|
| 清晰度 | 无模糊、无遮挡 |
| 显示完整 | 核心操作区域需完整显示 |
| 上下文间距 | 上下各1倍行距 |

## 八、页面设置规范

### 8.1 页边距

| 边距位置 | 尺寸 |
|----------|------|
| 上边距 | 2.5cm |
| 下边距 | 2.5cm |
| 左边距 | 2cm |
| 右边距 | 2cm |

### 8.2 纸张设置

| 设置项 | 要求 |
|--------|------|
| 纸张规格 | A4 |
| 排版方向 | 纵向（默认） |
| 横向排版 | 禁止（无特殊说明） |

### 8.3 页码设置

| 内容 | 要求 |
|------|------|
| 位置 | 页面底部居中 |
| 字体 | 宋体、小四 |
| 加粗 | 无 |
| 起始位置 | 从"一、文档前言"开始编号 |
| 不编号页 | 封面、版本说明页 |

### 8.4 页眉设置（若添加）

| 内容 | 要求 |
|------|------|
| 内容 | 标注文档总标题 |
| 字体 | 宋体、小四 |
| 对齐 | 居中 |
| 与页面顶部距离 | 1.5cm |

## 九、通用禁忌

| 禁忌项 | 说明 |
|--------|------|
| 手动换行 | 禁止，所有换行通过段落设置实现 |
| 格式多样 | 禁止同一类内容出现多种格式 |
| 过度使用 | 禁止过度使用加粗、彩色字体 |
| 红色使用 | 仅风险警示内容可使用红色 |
| 表格修改 | 禁止随意修改表格边框、列宽 |

## 十、Markdown转Word转换要求

### 10.1 需清除的标记

| 标记类型 | 符号 | 处理方式 |
|----------|------|----------|
| 标题 | #、##、###、#### | 清除标记，保留编号和文字 |
| 加粗 | **、* | 清除标记，保留加粗格式 |
| 引用 | > | 清除标记，转换为普通段落 |
| 特殊符号 | ✅等非标准符号 | 移除或替换为标准符号 |

### 10.2 已适配的符号（无需转换）

| 符号 | 状态 | 说明 |
|------|------|------|
| ● | ✅ 已适配 | 无序列表标准符号，无需转换 |

### 10.3 转换规则

| 原格式 | 转换结果 |
|--------|----------|
| "### 场景：" | "场景："作为普通段落或适当级别标题 |
| "## 功能模块" | 转换为"二、功能模块"作为一级标题 |
| "**加粗文本**" | 转换为普通加粗格式，移除星号 |
| "- 列表项" | 直接使用●符号（模板已预置） |

### 10.3 保留内容

| 内容类型 | 处理方式 |
|----------|----------|
| 标题编号 | 保留 |
| 标题文字 | 保留 |
| 正文内容 | 保留 |
| 表格 | 保留格式 |
| 图片 | 保留并调整大小 |

## 十一、文档结构模板参考

### 11.1 章节编号规范

```
一、大章节（一级标题）
    1. 小节（二级标题）
        1.1 子节（三级标题）
            1.1.1 细项（四级标题）
```

### 11.2 典型文档结构

```
文档总标题（封面）
├── 版本管理
├── 一、项目概述
│   ├── 1.1 背景介绍
│   └── 1.2 目标说明
├── 二、术语定义
├── 三、功能需求
│   ├── 3.1 模块一
│   │   ├── 3.1.1 页面简介
│   │   ├── 3.1.2 功能说明
│   │   └── 3.1.3 交互说明
│   └── 3.2 模块二
├── 四、权限说明
├── 五、非功能需求
└── 附录
```
