## 布局类型说明

| 布局类型 | 说明 | 适用场景 |
|----------|------|----------|
| 单栏布局 | 内容居中，单列展示 | 详情页、表单页 |
| 双栏布局 | 左右分栏 | 管理后台侧边栏 |
| 上下布局 | 顶部+主体+底部 | 移动端页面 |
| 卡片布局 | 多个卡片块 | 数据展示页 |
| 表格布局 | 行列分明 | 列表页、数据管理 |
